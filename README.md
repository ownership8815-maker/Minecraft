# MCreator

A free, open source Minecraft mod creation tool for both **Java Edition** and **Bedrock Edition**.

MCreator lets you build Minecraft mods without writing code from scratch. Design elements, define behaviors, and export a ready-to-run mod — all from a visual workspace.

## Supported editions and versions

| Edition | Supported Minecraft versions |
|---|---|
| Java Edition | All currently supported versions |
| Bedrock Edition | All currently supported versions |

## Supported mod loaders (Java Edition)

- Forge
- Fabric
- NeoForge

## Downloads

See the [Releases](https://github.com/ownership8815-maker/Minecraft/releases) page for the latest downloads.

- **Java Edition:** download the mod `.jar` from the release.
- **Bedrock Edition:** download the `.mcaddon` file and sideload it.

## Getting started

1. Download the release for your edition from the [Releases](https://github.com/ownership8815-maker/Minecraft/releases) page.
2. Install it following the instructions for your edition.
3. Open MCreator, create a new workspace, and start building.

## Contributing
