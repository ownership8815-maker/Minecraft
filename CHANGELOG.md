## [1.0.0] - 2026-10-20 - for Minecraft Java (all supported versions) and Bedrock (all supported versions)

### Added

- Initial public release of MCreator.
- Visual mod workspace for building Minecraft mods without writing code from scratch.
- Support for Forge, Fabric, and NeoForge mod loaders (Java Edition).
- Bedrock Edition add-on export as `.mcaddon`.
- Java Edition mod export as `.jar`.
- Element palette for defining blocks, items, entities, and procedures.
